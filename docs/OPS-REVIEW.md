# 参考评估：`T-Auto/dsh-ops` 值不值得抄

结论先说：**不是同类项目，不能互相替代；值得借的是它「工具结果怎么给模型看」这一层，只剩三条可搬。**

事实（2026-11-02 取自 npm registry 与 GitHub API）：

| 项 | 值 |
|---|---|
| 仓库 | `T-Auto/dsh-ops` |
| npm | `dsh-ops@0.4.4`（`latest`），另有 `beta` 线 `0.2.5-beta.1` |
| star | 5053 |
| license | MIT（`@dsh-ops/bash-win32-x64` 为 GPL-2.0） |
| 最近推送 | 2026-11-02 |
| 安装 | `npx --yes dsh-ops@latest install --profile desktop\|web\|tui` |

## 它是什么

按它自己的定位是「低改动面、低侵入性」的运行时增强。实际做法在三处：

1. **Windows 运行时分发**：把一套 bash/POSIX 工具链打包成平台专属二进制包随插件发下去，让 Windows 上的 DSH 也能跑 shell。
2. **工具面替换**：接管/重写一部分官方工具的暴露方式与结果呈现（`Native` 紧凑输出、`PTC` 结构化 JSON、`tools_addition` 渐进披露）。
3. **按工具类型定制的输出视图**：同一份结果，按工具类型压成更短的结构再交给模型。

## 与本项目的映射

| `dsh-ops` 的做法 | `dsh-fast-mode` 的对应 | 关系 |
|---|---|---|
| Windows 运行时分发、替换 shell | 不做，直接用宿主原生 shell | **不重叠**，它补的正是我们没有的平台缺口 |
| `Native` 紧凑输出（按工具类型压缩结果） | `compactResults`：超 `compactMaxChars` 只留头尾、写明省略量 | 同类但更粗；**可借鉴** |
| `PTC` 结构化 JSON 结果 | 无（我们刻意不改结果语义） | 仅在「不改语义」的安全子集里**部分可借鉴** |
| `tools_addition` 渐进披露 | 无（我们不隐藏工具，只用 `workspaceMap` 给一次工作区清单） | 机制相反：它藏、我们只提前给 |
| 提示/执行钩子里的 token 机制 | `probeFirst`/`actBeforePlan`/`repeatNudge`/`readCache`/`stallGuard` | 同一个杠杆位，**互补** |

它加速的路径是「少读结果、少猜工具用法」；我们加速的路径是「少往返、少过程文字、少等待」。两条路径可以同时成立，但都依赖提示与钩子，所以**同装要分开测**。

## 值得借鉴的三条

1. **结果视图按工具类型分开。** 我们现在是一套 `headTail` 压所有工具，`read`/`grep` 有专用分支，其余一律文本截断。它按工具类型给不同形状，这一层比我们细；可做的是给 `bash`/`ls`/`glob` 各一条轻量规则，仍保持「省略量写明、可逐字复原」。
2. **省略段要能被模型寻址。** 我们已经在正文里写了省略量（`[fast-mode: elided N chars]`），但没写省略的是哪一段（行号区间），模型只能选择整份重读或相信残缺版本。下一步该给的是「省略了第 120–480 行」这种可回读的地址，而不是更大的省略数字。
3. **渐进披露要有边界。** 不学「隐藏工具」，但可以学它的触发条件：只有当模型真的去试参数时才展开说明，而不是开局一次性给全。可搬到 `workspaceMap` 的测试入口提示上。

## 不值得抄的两条

1. **隐藏官方工具、替换 shell。** 这直接违反本项目「关掉就是原生、任何开关可反悔」的契约：工具面一旦被替换，用户在别处看到的工具列表、参数、错误文本都不再是官方的，回退也只能靠卸载插件。我们的每一个机制都必须能用一个布尔值关回原生，这条不让步。
2. **平台专属二进制随包分发。** 我们要保持零依赖纯 JS：`npm i` 装不上就完全不可用，比慢一点严重得多；GPL-2.0 组件随包传递也会让许可变复杂。Windows 用户的问题应该由宿主管，不该由一个 token 效率插件背。

## 这条评估不声称什么

- 没有在本机装 `dsh-ops`，没有跑它的基准；上面关于它机制的描述来自仓库文件树与 README，不是实测。
- 它的 star 数与「加速比例」无关；本项目自己的数字仍只以 `BENCHMARK.md` 与 `docs/REFERENCE.md` 里带置信区间的那几条为准。
